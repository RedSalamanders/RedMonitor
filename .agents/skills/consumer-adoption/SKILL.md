# consumer-adoption

Read Specs/Build/Build_Consumption.md and the owning consumer contract. Vendor only Client.h and LICENSE.txt
at an immutable commit with exact Git-blob SHA-256 values and -text checkout policy. Normal builds verify local
bytes; never restore/build/stage the viewer in a consumer. Dependency updates are explicit. Discover only the
standard separately installed production Release helper. Debug bare startup may launch it; Release/help/test
paths do not. Preserve app logging/crash fallback, provider ownership and plugin ABI. Qualify normalized real
ETW, absent/invalid helper behavior, all affected native profiles and application packaging independently.
